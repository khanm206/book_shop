# 📚 Book Shop App

✨ *A modern React-based Book Shop web application with smooth UI, animations, and data visualization.*

This project simulates a simple e-commerce experience where users can browse books, view details, and explore visual insights through charts.

---

## 🚀 Live Demo
🌐 https://book-shop-mk.netlify.app

---

## 🛠️ Tech Stack

⚛️ React.js  
🟨 JavaScript (ES6+)  
📡 Axios (API handling)  
🎞️ Framer Motion (animations)  
📊 Recharts (data visualization)  
🧭 React Router DOM (navigation)  
🎨 HTML5 + CSS3  
🚀 Netlify (deployment)

---

## ✨ Features

📖 **Book Listing System**  
- Browse a collection of available books

🔍 **Book Details View**  
- Click any book to see full information

🎞️ **Smooth Animations**  
- Page transitions powered by Framer Motion

📊 **Interactive Data Visualization**  
- Charts powered by Recharts for better insights

🌐 **API Integration**  
- Dynamic data fetching using Axios

🧭 **Multi-page Navigation**  
- Seamless routing using React Router

📱 **Responsive Design**  
- Fully optimized for mobile, tablet, and desktop
