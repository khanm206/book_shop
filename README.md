# 📚 Book Shop App

A modern Book Shop web application built with React.  
It demonstrates a simple e-commerce UI with smooth animations, data visualization, and API handling.

---

## 🚀 Live Demo
👉 https://book-shop-mk.netlify.app

---

## 🛠️ Tech Stack

- React.js
- JavaScript (ES6+)
- Axios (API handling)
- Framer Motion (animations)
- Recharts (data visualization)
- React Router (navigation)
- HTML5 + CSS3
- Netlify (deployment)

---

## ✨ Features

- 📖 Browse list of books
- 🔍 View detailed book information
- 🎯 Smooth page animations using Framer Motion
- 📊 Data visualization using Recharts
- 🌐 API integration using Axios
- 🧭 Multi-page navigation with React Router
- 📱 Responsive UI design

---

## 🎬 UI & UX Highlights

- Smooth transitions between pages
- Animated components for better user experience
- Interactive charts for visual insights
- Clean and minimal layout
